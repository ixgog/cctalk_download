# CCtalk 网课下载

> **新版工具 [CCDown](https://prepare.ccdown.top:8443/)** 已发布：配合本机 CCTalk 桌面端，支持下载账号下更多类型的课程（含原先「仅客户端可看 / 有版权保护」一类）。  
> 旧版（本仓库 PyQt + 浏览器登录）主要覆盖**未加密 / 可直链**的课时，能力有限，仅作历史参考。

## 推荐：CCDown（当前主推）

- 介绍与下载：**<https://prepare.ccdown.top:8443/>**
- Windows 桌面版，向导式操作
- 浏览已购课 → 勾选批量下载 → 本地用第三方播放器观看
- 仅限**个人学习**；禁止二次分发、上传、出售或公开分享

**安装与使用**（摘要）：

1. 安装并登录 Windows 版 [CCTalk 桌面客户端](https://www.cctalk.com/download)
2. 从落地页下载 CCDown 压缩包，整包解压后运行 `CCDown.exe`
3. 首次启动需同意用户协议
4. 按界面：启动 CCTalk → 登录 → 播放任意一节 → 选课下载

### 旧版使用方式

点击登录会弹出浏览器进入 cctalk 官网，正常登录后程序会自动获取用户信息。

![](img/Snipaste_2025-06-14_01-44-48.png)

「我的课程」为下拉框，选择课程后可解析课时列表并按需下载。

![](img/Snipaste_2025-06-14_01-47-57.png)

支持进度显示；已存在文件会跳过（不检查完整性）。

![](img/Snipaste_2025-06-14_01-48-40.png)
